# ⚡ PulseDesk - Enterprise Support Ticket & Customer Management System

PulseDesk is a high-performance, scalable backend RESTful API built with **Django 6.x** and **Django REST Framework (DRF)**.

## 🚀 Key Features (In Progress)
- **Modular Architecture**: Clean code structure separation.
- **Environment Security**: Secure config separation using `python-decouple`.
- **Advanced Database Design**: Normalized ORM models with indexing & soft deletes.

## 🛠️ Tech Stack
- **Language:** Python 3.14+
- **Framework:** Django 6.0, Django REST Framework
- **Database:** SQLite (Dev) / PostgreSQL (Prod)
